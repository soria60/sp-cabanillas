# Sp. Cabanillas – Interescuelas Alevín G3 (2026-27)

Clasificación, resultados y calendario del Sp. Cabanillas. Datos de la Federación de Fútbol de Castilla-La Mancha.

Web: https://soria60.github.io/sp-cabanillas/

## Archivos
- `index.html` – la web (lee los datos de `datos.json`).
- `datos.json` – calendario y resultados de todo el grupo.
- `Clasificacion_Interescuelas_Alevin_G3.xlsx` – el Excel con clasificación y calendario (se actualiza a la vez).
- `herramientas/extractor.js` – lee los marcadores reales de la web de la FFCM desde el navegador.
- `herramientas/aplicar.py` – aplica lo extraído a `datos.json` y al Excel.

## Privacidad
No se publica ningún nombre de jugadora.
